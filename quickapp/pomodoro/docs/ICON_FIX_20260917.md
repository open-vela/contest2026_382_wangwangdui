# pomodoro 图标不可见 —— 根因与修复

## 结论

蜂窝启动器里看不到番茄钟，是**图标文件本身无法解码**，外加设备上跑的是旧构建：

1. `src/common/pomodoro-icon.png` 的第一个 IDAT 分块 CRC 与内容不符，zlib 数据流无法解压。AIoT 图像转换器直接以 `CrcMismatch(ChunkType { type: IDAT })` 拒绝该文件；不生成 `.bin` 说明构建期就已经失败，启动器渲染时自然拿不到位图。
2. 设备侧当时仍指向旧素材：安装包里的 manifest 是 `/common/logo.png`（96×96），而源码早先已改成 192×192 的 `pomodoro-icon.png`，但那次改动从未重新构建进包。

## 证据链

| 位置 | 修复前 | 修复后 |
|---|---|---|
| `src/common/` | `logo.png` 96×96 (1637 B) + 损坏的 `pomodoro-icon.png` | 只剩有效的 `pomodoro-icon.png` 192×192 (9037 B) |
| `src/manifest.json` | `/common/pomodoro-icon.png` | 同上（未改） |
| `build/manifest.json` | `/common/logo.png`（旧构建） | `/common/pomodoro-icon.png` |
| 设备 `/data/app/com.application.pomodoro/manifest.json` | `"icon": "/common/logo.png"` | `"icon": "/common/pomodoro-icon.png"` |
| 设备 `/data/app/com.application.pomodoro/common/` | `logo.png` (1637 B) + `logo.bin` | `pomodoro-icon.png` (9037 B) + `pomodoro-icon.bin` (153676 B) |
| 设备 `/data/apps.json` 条目 | `"icon": "common/logo.png"` | `"icon": "common/pomodoro-icon.png"` |

包名与入口本来就正确：`com.application.pomodoro`，`am start` 后进程常驻运行；启动器状态库 `/data/app/home/home.db` 只存布局与排序（unqlite：`layout_v001`、`widget_sort_v002`），不缓存图标位图，所以图标完全由包内 manifest 与包内位图决定。

## 修复步骤

```bash
# 1. 删掉旧的 96x96 素材，让 manifest 指向的 PNG 成为唯一图标来源
rm quickapp/pomodoro/src/common/logo.png

# 2. 从 SVG 重新生成 192x192 图标，并校验 PNG 分块 CRC
cd quickapp/pomodoro && python tools/render_icon.py

# 3. 重新构建（aiot build 会顺带生成 LVGL 用的 .bin）
cd quickapp/pomodoro && npm run build

# 4. 安装到模拟器并核对设备侧文件
adb -s emulator-5554 push dist/com.application.pomodoro.debug.1.0.0.rpk /tmp/pomodoro.rpk
adb -s emulator-5554 shell pm install /tmp/pomodoro.rpk
adb -s emulator-5554 shell cat /data/app/com.application.pomodoro/manifest.json
adb -s emulator-5554 shell ls -l /data/app/com.application.pomodoro/common
```

重建后包内同时出现 PNG 与 LVGL `.bin`：`.bin` 只会在 PNG 能被解码时生成，因此它的存在本身就是图标有效的证据。

## 证据范围

- 已核验：图标分块 CRC 与 zlib 流、构建产物、安装包、设备内 manifest 与图标文件、`/data/apps.json` 条目、应用可启动。
- 独立于本文件的界面确认：在模拟器上滑入应用列表，番茄钟磁贴显示为深色圆角底 + 橙色番茄 + 绿色叶片 + 深色表盘。

## 回归守护

图标链路固定为 `design-assets/app-icon.svg` → `tools/render_icon.py` → `src/common/pomodoro-icon.png`（192×192）→ `manifest.icon`。`render_icon.py` 在写出 PNG 后会校验每个分块的 CRC、IDAT 流可解压以及最终尺寸，任何一步失败都会直接报错退出，避免再出现“源码正确、设备照旧”。
